# Controle Logístico JSL GWM

1. No Supabase > SQL Editor, execute `supabase/schema.sql`.
2. Na Vercel, importe este projeto.
3. Cadastre as variáveis de ambiente do `.env.example`.
4. Faça deploy.

Telas: Portaria, Recebimento, Produção x Entrega, Unpacking B/P, Docas/Recuo, Histórico e TV Operacional.
